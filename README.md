# DevSnippets AI 🚀

An offline-first developer utility app built with React Native, Expo, SQLite, and AI integration.

## 📱 Features

* Create and manage code snippets
* Edit and delete snippets
* Favorite snippets
* Search snippets instantly
* Local SQLite database storage
* Import code files
* Export code files
* AI-powered code explanation
* Secure API key storage
* File management system
* Modern bottom tab navigation
* Offline-first architecture

## 🛠 Tech Stack

* React Native
* Expo
* Expo Router
* TypeScript
* SQLite
* Zustand
* Expo Secure Store
* Expo File System
* Expo Document Picker
* Axios
* Lucide React Native Icons
* OpenRouter API

## 🚀 Installation

1. Clone the repository

git clone <repository-url>

2. Install dependencies

bun install

3. Start Expo

bun expo start

## 🔑 OpenRouter Setup

1. Create an OpenRouter account
2. Generate an API key
3. Open the Settings screen
4. Save your API key securely
5. Use AI Explain Code feature
